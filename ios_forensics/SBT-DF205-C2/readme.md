This lab involved the forensic examination of an iPhone SE running iOS 13.4.1 using a supplied forensic extraction, with selected databases and supporting files extracted and analysed while preserving relevant SQLite files and their WAL/SHM sidecars. We examined device information, settings, accounts, messages, contacts, call history, Safari activity, calendar records, photo metadata, application activity, health sources, and location artefacts, documenting relevant findings and timestamps in UTC. The results were compiled into a forensic report and supporting evidence register, timeline, handling log, selected metadata extracts, and SQL queries, with limitations clearly recorded where data or supporting media files were unavailable.
